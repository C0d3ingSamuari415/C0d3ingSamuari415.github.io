# Packet Analysis Lab — DNS Tunneling Investigation

## 📝 Overview
This lab focuses on detecting DNS tunneling, a technique attackers use to exfiltrate data or maintain covert communication.

## 🎯 Objectives
- Identify abnormal DNS queries  
- Analyze domain entropy  
- Validate suspicious domains  
- Document findings  

## 🔧 Tools Used
- Wireshark  
- Zeek  
- OSINT  

## 🧪 Investigation Steps
1. Load PCAP  
2. Filter DNS traffic  
3. Identify long or encoded queries  
4. Validate domains  
5. Document findings
