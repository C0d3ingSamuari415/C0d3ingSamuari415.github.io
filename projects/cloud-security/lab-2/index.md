# Cloud Security Lab — AWS IAM Misconfiguration Investigation

## 📝 Overview
This lab focuses on identifying and analyzing insecure IAM policies that could lead to privilege escalation or unauthorized access.

## 🎯 Objectives
- Identify overly permissive IAM roles  
- Analyze attached policies  
- Test escalation paths  
- Document findings  

## 🔧 Tools Used
- AWS IAM  
- AWS CloudTrail  
- Policy Simulator  
- OSINT (optional)  

## 🧪 Investigation Steps
1. Review IAM roles and policies  
2. Identify wildcard permissions (`*`)  
3. Test privilege escalation scenarios  
4. Validate CloudTrail logs  
5. Document findings
