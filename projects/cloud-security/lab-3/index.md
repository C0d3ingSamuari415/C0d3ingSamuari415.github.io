# Cloud Security Lab — Azure Sentinel Detection Engineering

## 📝 Overview
This lab focuses on building and testing a detection rule in Azure Sentinel using KQL.

## 🎯 Objectives
- Analyze Azure logs  
- Identify suspicious activity  
- Build a KQL detection rule  
- Validate the detection  

## 🔧 Tools Used
- Azure Sentinel  
- Log Analytics Workspace  
- KQL  
- Azure Activity Logs  

## 🧪 Investigation Steps
1. Identify suspicious behavior  
2. Query logs using KQL  
3. Build detection logic  
4. Test detection with sample events  
5. Document findings
