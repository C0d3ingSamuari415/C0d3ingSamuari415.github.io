# IAM Security Lab — Identity Threat Hunting

## 📝 Overview
This lab focuses on detecting suspicious identity behavior such as impossible travel, MFA fatigue, or anomalous sign-ins.

## 🎯 Objectives
- Analyze identity logs  
- Identify suspicious sign-in patterns  
- Validate anomalies  
- Document findings  

## 🔧 Tools Used
- Azure AD Sign-In Logs  
- AWS CloudTrail  
- SIEM (Sentinel / Splunk / Elastic)  

## 🧪 Investigation Steps
1. Query identity logs  
2. Identify anomalies  
3. Validate with OSINT or geo data  
4. Document findings
