# IAM Security Lab — Azure AD Privilege Escalation

## 📝 Overview
This lab focuses on identifying Azure AD misconfigurations that allow privilege escalation or unauthorized access.

## 🎯 Objectives
- Identify risky Azure AD roles  
- Analyze sign-in logs  
- Validate escalation paths  
- Document findings  

## 🔧 Tools Used
- Azure AD  
- Azure Sign-In Logs  
- Azure Portal  
- Entra ID  

## 🧪 Investigation Steps
1. Review Azure AD roles  
2. Identify risky assignments  
3. Test escalation scenarios  
4. Validate logs  
5. Document findings
